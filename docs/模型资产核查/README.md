## 结果

| 模型 | 划分 | 图片数 | Precision | Recall | mAP50 | mAP50–95 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| PPE | 历史验证 | 1,414 | 83.43% | 87.68% | 89.02% | 64.33% |
| PPE | 本次现有 test | 707 | 82.71% | 87.96% | 88.84% | 62.59% |
| 器皿 | 历史验证 | 517 | 86.70% | 85.10% | 89.27% | 73.73% |
| 器皿 | 本次现有 test | 254 | 83.80% | 87.61% | 90.00% | 71.92% |

本次环境为 Python 3.11.15、PyTorch 2.14.1、Ultralytics 8.4.95；CPU（arm）、batch=8、imgsz=640、conf=0.001、NMS IoU=0.7、max_det=300、workers=0，不使用测试时增强。两个模型的验证任务同时运行。原数据被复制到临时目录后评估，缓存也在临时副本中生成。PPE 原训练框架为 8.3.82，本次不是同版本的逐位重放。

## 来源和文件路径

JSON 保留核查时的原字段和路径，便于追溯，而不是可直接执行的本机配置：

- `hierarchical-lab-safety-monitor/labguard/models/…` 是相对比赛总资料目录的路径，在本仓库中对应 `labguard/models/…`。
- `AIVision程序/…` 指比赛总资料中的原数据和训练目录，不在本仓库内。
- `train_args` 中的 Windows / Linux 绝对路径属于历史训练元数据，换电脑时不能直接照用。
- 测试结果中的 `weights_sha256` 可与当前仓库权重重新计算的 SHA-256 比对。

PPE 本地数据名称为 `Safe Lab A(dst3542)`，其 12 类和 5,096 / 1,414 / 707 的划分与公开 [Safe Lab AI v4](https://universe.roboflow.com/sara-dea2a/safe-lab-ai/dataset/4) 一致。对应关系属于高可信推断，仍缺原始下载记录及逐图核验；公开项目发布者不等于已确认的原始采集者。器皿最终配置指向 14 类的 `chemical-lab02`，原始来源未确证。

## 指标的边界

- 这是目标检测评估，不是事故预防成功率或危险事件识别率。
- PPE 有 31 个疑似源视频前缀组同时分布于训练、验证和测试；相近帧可能高估跨场景泛化能力。
- 全部图片 SHA-256 检查未发现跨划分字节完全相同的文件，但没有排除近重复画面。
- 器皿若干类别测试样本很少，例如圆底烧瓶 3 个、漏斗 4 个、洗瓶 7 个标注框，不能把高 AP 当作普遍可靠的结论。
- 现有数据没有统一条件下与其它检测器的完整对比，也未形成跨实验室、手机实拍或硬件干预 benchmark。
- 两份 JSON 的速度是本次 CPU、batch=8、同时验证的阶段平均耗时，不能直接当作单路摄像头或完整双摄系统帧率。
